Here are concise terms you can reuse in future prompts:

---

**Good phrases to use:**

1. **“Give me deep links to the code”** or **“Add deep links to the code”**
- “Deep link” = link that opens a specific place (file + line), not just the file.
1. **“Use clickable file:line links”** or **“Link to exact line numbers”**
- Very clear that you want links that open at a given line.
1. **“Add in-repo / workspace links to the code”**
- Emphasizes links that work inside your repo/IDE (e.g. relative path + #L123).

---

**Short prompt you can copy:**

- *“When you reference code, give me **clickable deep links** (file path + line) so I can jump to the exact line in my editor.”*

or:

- *“Reference code with **deep links** (e.g. path/to/file.c#L123) so I can Ctrl+Click to open at that line.”*

---

**One term to remember:** **deep links** (to code / to source / to exact lines). Using that in a prompt will get you the same kind of clickable, line-specific links.
